- 后端：`splitDocumentIntoChunks` 接受 `strategy` + `delimiter` 参数；新增 `POST /api/knowledge/preview-chunks` 预览接口
- 上传时透传 `chunkStrategy` / `delimiter` / `maxChars` 到后端

**状态**：**已修复**。按 `docs/上传切片策略设计文档.md` 全量实现：
- 后端 `chunker.js`：新增 `splitByDelimiter`；`splitDocumentIntoChunks` 支持 `strategy`/`delimiter`/`config.maxChars` 分支（delimiter 模式跳过语义细切与过短块合并，尊重用户显式分隔符；保留 `enforceHardMax` 安全兜底）。
- 后端 `index.js`：新增 `POST /api/knowledge/preview-chunks`（零副作用预览，含参数校验）；上传端点读取 `chunkStrategy`/`delimiter`/`maxChars` 并透传 `prepareDocChunksAndVectors`。
